# 보너스: 폰으로 펀치 세기 재기

[PRODUCT.md](../../../PRODUCT.md)의 재미 우선 원칙을 따르는 보너스 게임이다. 폰을 컨트롤러로 연결해 10초 동안 친 펀치의 세기를 기록한다. 본 리듬게임의 판정에는 영향을 주지 않는다.

연결된 원천:
- [ui-composition](../../decisions/ui-composition.md) — 보너스 화면은 shadcn Dialog, Card, Button으로 구성한다.
- [dependency-versions](../../decisions/dependency-versions.md) — 새 의존성(`qrcode`) 버전 규칙.

## 사용자에게 보이는 결과

1. 홈 화면 로고에서 복서의 골드 글러브(주먹)를 누르면 숨은 보너스 창이 열리고 QR 코드와 폰용 주소가 보인다.
2. 폰으로 QR을 찍어 연 페이지에서 "센서 허용하고 연결"을 누르면 컴퓨터 화면이 "폰이 연결됐습니다"로 바뀐다.
3. 컴퓨터에서 시작을 누르면 3초 카운트다운 뒤 10초 동안 방금 친 세기와 친 횟수가 실시간으로 보인다.
4. 끝나면 가장 센 한 방, 평균 세기(G 단위), 친 횟수를 보여 주고 다시 할 수 있다.

## 수용 기준

- AC1. 설정 화면에는 보너스 버튼이 보이지 않는다. 로고의 글러브를 누르면 보너스 창이 열리고, 같은 와이파이의 폰이 열 수 있는 주소와 그 QR 코드가 보인다.
- AC2. 폰 페이지에서 연결하면 컴퓨터 화면이 연결됨 상태로 바뀌고 시작할 수 있다.
- AC3. 폰 가속도가 약 1.5G(15 m/s²)를 넘었다가 내려오면 그 사이 가장 큰 값을 세기로 한 번의 펀치로 센다. 펀치 직후 0.3초 안의 되튐은 세지 않는다.
- AC4. 시작 후 3초 카운트다운, 이어서 10초 동안만 펀치를 기록하고, 결과로 가장 센 한 방·평균 세기·친 횟수를 0.1G 단위로 보여 준다.
- AC5. 폰 페이지가 HTTPS가 아니면 센서가 열리지 않는 이유와 해결 방법을, 방 번호 없이 열리면 QR로 들어오라는 안내를 보여 준다. 컴퓨터 화면도 HTTPS가 아니면 같은 경고를 보여 준다.
- AC7. 결과가 나오면 화면 전체에 색종이와 빵빠레가 나오고, 이름을 적어 기록(가장 센 한 방·평균·횟수)을 이 브라우저(localStorage)에 저장할 수 있다. 가장 센 한 방 순 상위 5개가 보인다. 이름은 본게임과 함께 쓰는 지난번 이름이 미리 채워진다.
- AC6. 아이폰에서는 연결 버튼을 누를 때 움직임 센서 권한을 요청하고, 거부하면 다시 시도하라고 안내한다.

## 확정된 제약과 근거

- 세기 측정은 본 게임과 분리된 보너스 게임이다. (사용자 확정)
- 방식은 10초 동안의 최고 세기 기록이다. (사용자 확정)
- 보너스는 이스터에그로, 로고의 글러브를 눌러야만 열린다. 글러브가 작아서 누르는 영역은 글러브보다 조금 넓게 잡는다. (사용자 확정)
- 폰은 개발 서버의 HTTPS(`bun run dev:phone`)로 연다. 설치할 것이 없지만 폰에서 인증서 경고를 한 번 넘겨야 한다. (사용자 확정)
- 폰과 컴퓨터 사이의 중계는 개발 서버 안의 라우트로 한다. 별도 서버나 외부 서비스가 필요 없다. Supabase는 사용자가 다시 쓰기로 할 때까지 쓰지 않는다. (사용자 지시)

## 가정 (바꿀 수 있음)

- 펀치 기준 15 m/s², 되튐 무시 0.3초는 실제로 해 보며 조정한다.
- 폰에서 중력이 빠진 가속도를 주지 않으면 중력 포함 가속도에서 1G를 빼서 쓴다.
- 방 번호는 컴퓨터 화면을 열 때마다 새로 만들고, 중계는 개발 서버 메모리에만 둔다.

## 범위 밖과 이유

- 본 게임 판정에 폰 신호를 쓰는 것, 두 기기의 시계 맞추기 — 보너스 게임은 타이밍 판정이 없어 필요 없다.
- 폰 두 대(양손) 연결 — 요청되지 않음.
- 배포 환경에서의 중계(여러 서버 인스턴스) — 강의용 로컬 실행만 대상이다.

## 남은 위험

- 회사·공용 와이파이는 기기끼리의 접속을 막아 폰이 컴퓨터 주소를 못 열 수 있다.
- 폰 브라우저에 따라 인증서 경고를 넘긴 페이지에서 센서를 막을 수 있다. 그때는 터널(`cloudflared` 등)로 정식 HTTPS 주소를 써야 한다.
- 컴퓨터에 네트워크 주소가 여러 개면 QR에는 첫 번째 주소만 들어가 폰이 열 수 없는 주소일 수 있다.
